# Karyana Shopkeeper Portal

A responsive web application for shopkeepers to manage their daily store operations.

## Features

- Secure login and protected routes
- Dashboard with shop overview
- Product management
- Category management
- Customer management
- Supplier management
- Search and filtering
- Add, edit, view and delete functionality
- Form validation
- Responsive design for desktop, tablet and mobile
- Loading, error and empty states

## Technologies Used

- React
- Vite
- JavaScript
- Tailwind CSS
- React Router
- Axios
- React Hook Form
- React Toastify
- Lucide React
